About this build

StudyDock is a single Chromium extension. The always-active engine is merged with the Canvas page guard, quiz loader, kiosk bar, and toolbar. There is no subscription, login, trial, usage counter, analytics endpoint, or remote asset dependency.

Version 2.0.0 · Settings are stored with chrome.storage.local.
